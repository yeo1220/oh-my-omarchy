# 출처

이 저장소는 Omarchy 사용자 설정과 로컬 개선을 모은 것입니다. 독립적인 Omarchy 배포판이나 공식 프로젝트가 아닙니다.

- 기반 프로젝트: https://github.com/basecamp/omarchy
- `lovehouse.*` 셸 플러그인은 설치된 Omarchy 플러그인을 복제·수정한 사용자 버전을 포함합니다. 각 `manifest.json`의 원본 및 기존 문서를 보존했습니다.
- 테마의 `shell.toml`, 설정 템플릿, 로고 SVG 등에는 상위 프로젝트에서 가져온 내용이 포함됩니다.
- Graphite Atelier `01-dark-waters.jpg`: 설치된 Omarchy Matte Black 배경에서 가져옴.
- Midnight Orbit 배경: 설치된 Omarchy Nord `0-black-moon.jpg`에서 가져옴. 두 파일명은 현재 로컬 구성을 보존합니다.
- Champagne Ridge: 로컬 생성 배경. 생성 프롬프트를 같은 폴더에 포함했습니다.

기존 코드·상표·자산의 권리는 각 원저작자에게 있습니다. 이 초기 수집에서는 전체 파일에 새 단일 라이선스를 부여하지 않습니다.
